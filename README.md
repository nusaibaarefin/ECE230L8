## Lab Questions

### In plain English describe the function and use of a multiplexer.
Multiplexers selects one of several inputs and sends it to a single output.

### In plain English describe the function and use of a demultiplexer.
Demultiplexer takes a single input and sends it to one of several outputs.

### What other uses might these circuits have? (Think Shannon’s)
They can be used to route data between different devices and circuits.
